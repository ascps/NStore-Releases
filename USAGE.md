# Использование NStore

1. Откройте DMG из [публичных релизов](https://github.com/ascps/NStore-Releases/releases/latest) и перетащите **NStore** в **Программы**. В сборке применена локальная подпись ad hoc. На другом Mac Gatekeeper может запросить отдельное подтверждение запуска. [Инструкция Apple](https://support.apple.com/ru-ru/102445)
2. Подключите iPhone или iPad кабелем и разблокируйте его. При первом подключении подтвердите доверие на Mac и на устройстве. Если запрос не появился, выберите устройство в боковой панели Finder и начните сопряжение там.
3. Откройте **Покупки Apple ID**, войдите в учётную запись и введите код с доверенного устройства, если Apple запросит 2FA. Кнопка «Получить код по SMS» открывает инструкцию для запроса SMS на доверенный номер на сайте Apple. [Как Apple отправляет код](https://support.apple.com/ru-ru/102606) При первом входе ipatool может несколько минут загружать и проверять служебные компоненты с CDN Apple.
4. Нажмите **Скачать**, чтобы сохранить IPA в библиотеке, или **Восстановить**, чтобы скачать его и отправить на выбранное USB-устройство. В **Библиотеке IPA** можно импортировать собственный файл, открыть его в Finder или установить по USB без входа в NStore.

Во всех списках отметьте нужные строки круглыми отметками или нажмите **Выбрать все** и выберите действие. Задачи выполняются последовательно. Кнопка очереди показывает ожидающие задачи, а колокольчик — результаты операций. Ожидающие задачи можно убрать из очереди до запуска. Из **Библиотеки IPA** можно экспортировать, установить или переместить в Корзину несколько файлов сразу. Раздел **Каталог приложений** показывает известные выпуски отдельными строками и позволяет дополнить их поиском по названию, App Store ID и Bundle ID в регионе учётной записи. При старте NStore восстанавливает недостающие иконки из уже сохранённых IPA.

В **Произвольном ID** можно вставить список числовых App Store ID или ссылок Apple, убрать лишние позиции и поставить остальные в очередь. Кнопка **Каталог** открывает справочник с избранным. В разделе с iPhone контекстное меню имени позволяет копировать Bundle ID или Apple ID приложения, если устройство его сообщило. В библиотеку можно перетаскивать IPA из Finder. Кнопка со стрелкой показывает очередь, колокольчик — историю операций. В **Настройках** можно выбрать папку IPA, просмотреть и сохранить системный журнал и проверить обновление из локального DMG. Раздел **Аккаунт** зарезервирован для следующего обновления.

История включает приложения, которые Apple вернула для этой учётной записи. NStore запрашивает пакет по числовому App Store ID. Если Apple требует лицензию, NStore Core может запросить её и повторить загрузку для приложения, которое Apple подтвердила как бесплатное в регионе аккаунта. Этот путь может сработать для приложения, снятого с публичной витрины. Для повторной загрузки Apple должна по-прежнему выдавать пакет для учётной записи. При отсутствии выдачи можно использовать свою сохранённую копию, если iOS принимает её подпись и лицензию. IPA восстанавливает приложение, а данные приложения зависят от его собственной синхронизации или резервных копий. [О повторной загрузке приложений](https://support.apple.com/ru-ru/108105)

В разделе **Со старого iPhone** выберите подключённое устройство и фильтр **Сгруженные**. Строка показывает App Store ID, Bundle ID и состояние, которое сообщает iOS. **Восстановить** устанавливает сохранённый IPA или запрашивает пакет у Apple по App Store ID и устанавливает его поверх заглушки. Если у приложения больше нет предложения для текущего региона, NStore пробует повторную загрузку по номеру сборки, который сохранило устройство. iOS хранит данные сгруженного приложения, а пакет для восстановления выдаётся Apple при его доступности для Apple ID. При переносе на другой iPhone сначала сохраните IPA в библиотеку, затем подключите новое устройство.

Кнопка **Устройства и Apple ID** открывает сохранённые устройства и логины. Для сохранённых устройств можно просматривать последний список приложений после отключения. Запомненный логин подставляется при следующем входе. Пароль вводится заново. Колокольчик открывает историю скачиваний и установок с возможностью её очистить.

Пароль и код передаются встроенному помощнику через локальный канал и отправляются по HTTPS в сервис Apple. Apple-сессия хранится в памяти до выхода из Apple ID или завершения NStore. Скачанные IPA и индекс библиотеки находятся в `~/Library/Application Support/NStore/IPA`. Подлинные App Store IPA могут включать метаданные учётной записи и привязанную к ней лицензию.
